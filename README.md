# AI 工作台行业营销策略研究报告

围绕“AI 产品是谁、服务谁、如何建立品牌认知、适合怎样的传播场景”展开的网页研究报告。报告以分众传媒销售场景为分析视角，将产品分类、用户决策链与营销策略整理为可浏览的资料页。

## 报告结构

- **市场与用户决策地图**：区分个人用户、专业岗位使用者和企业采购决策者。
- **产品营销地图**：页面标注覆盖 52 款产品，涉及通用助手、办公、智能体平台、开发、创意、行业垂直及系统级 AI。
- **重点客户分析**：页面标注 20 个重点分析对象，整理产品判断、销售对象、心智策略与传播方案。
- **营销方法论**：将产品类型、传播诉求、目标人群与媒介场景对应。
- **未来趋势**：讨论产品整合、任务执行、组织协作与 AI 终端等方向。

## 阅读体验

支持章节导航、可折叠目录与客户分析卡片，便于快速定位和对照阅读。

## 如何打开

1. 在仓库首页选择 **Code → Download ZIP**，下载并解压。
2. 用浏览器打开 `index.html`。
3. 使用目录定位章节，点击客户卡片展开分析。

项目由单个 `index.html` 文件构成，包含 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 信息范围与使用说明

- 报告标注的信息时间为 **2026 年 8 月**；产品名称、能力、规模及商业模式可能变化。
- 当前页面未提供完整的外部来源链接与逐项核查记录，相关事实在正式引用前应重新核实。
- 营销主张和客户机会属于分析与方案示例，不代表相关企业已采纳或已达成合作。
- 当前项目是静态研究报告，尚未实现自动更新的产品数据库。
